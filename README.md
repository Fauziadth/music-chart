## Music Chart
Simple application to learn how to visualize music chart 

This project was initiated with [Create React App](https://github.com/facebook/create-react-app).

Credits
- Last FM API https://www.last.fm/api
- UI package library https://ant.design/


## Available Scripts

In the project directory, you can run:

### `npm install`

Installing/downloading the necessary dependency.

### `npm start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
